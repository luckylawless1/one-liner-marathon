One-Liner Marathon entry: a single comedy one-liner, generated and verified by an AI agent program. The program writes the joke to /output/entry.txt, enforcing the competition gate (exactly one line, 1–280 characters, non-blank) and verifying the written file byte-for-byte on every run.

## Run it

```sh
node main.ts
```
